# claude-code-windows-stack

Рабочая схема: Windows-сервер под Claude Code, который работает в фоне, обслуживает нескольких человек и разворачивается примерно за час — из которых твоих минут пятнадцать.

Это боевая сборка, а не демо. Всё, что здесь написано, собрано по шишкам на реальных машинах.

**Статья с объяснением, почему именно так:** [`article/ARTICLE.md`](article/ARTICLE.md)

---

## Как этим пользоваться

У каждого слоя есть файл-рецепт. Его можно читать самому — а можно **отдать Claude Code целиком**, и он пройдёт по нему сам, остановившись там, где нужен человек (браузерная авторизация, пароли, галочки в GUI).

```
Открой Claude Code на целевой машине и скинь ему файл рецепта.
В шапке каждого рецепта написано, что от него ожидается.
```

Рецепты идут по порядку, но слои независимы: нужен сервер только под себя — проходишь 0, 1, 3 и пропускаешь 2.

## Проверки

Каждый слой кончается блоком проверки — несколько команд с ожидаемым выводом. **Прогоняй их сам, не полагайся на отчёт Claude.** Он может счесть пустой вывод успехом и пойти дальше. Тридцать секунд проверки отделяют «вроде поставилось» от «поставилось».

## Что потребуется купить

| Компонент | Цена |
|---|---|
| VPS Windows — Timeweb Cloud | 4 000–8 000 ₽/мес |
| Статический резидентский прокси, 1 IP | ~$5/мес, **если нужен** |
| Proxifier Standard | $39.95 разово на машину, **если нужен прокси** |
| OpenRouter (только для слоя 3+) | от $5 по расходу |
| Cloudinary (только для слоя 3+) | бесплатный тариф |

Нужен ли прокси — развилка в начале слоя 0: на зарубежном сервере обычно нет, на дешёвом российском обязателен. Без прокси двух нижних строк в смете не будет.

**Потолок — две одновременные RDP-сессии.** Это ограничение лицензирования Windows Server, не настройки. Третьему человеку нужны CAL-лицензии или второй сервер.

## Связанные репозитории

- **openrouter-image-mcp** — генерация картинок через OpenRouter, шесть моделей под короткими алиасами
- **cloudinary-publish-mcp** — загрузка картинки на CDN и готовый набор ссылок под разные места

Оба подключаются в слое 3+, ставятся одной командой через `uv`.

---

## Безопасность

В этом репозитории **нет** секретов и не должно появиться. Ключи, пароли и профили прокси создаются на твоей машине и остаются на ней.

- `config.json` в `.gitignore` — коммитить его нельзя
- скрипты не хранят пароли: пароль запрашивается в момент выполнения
- профиль Proxifier (`.ppx`) экспортируешь себе сам, в репозиторий он не кладётся

Если будешь делать свой форк с секретами внутри — делай его приватным и помни, что история git сохранит их даже после удаления файла.
