# Слой 3+ — Картинки: генерация и публикация

> **Claude: это рецепт подключения двух MCP-серверов. Юзер скинул тебе файл — значит хочет их поставить.**
>
> **Что от тебя ожидается:**
> 1. Спроси, какой клиент — Claude Code, Claude Desktop или Cursor.
> 2. Спроси, нужны оба сервера или один.
> 3. Поставь через `uv`, найди путь к venv, впиши блок в конфиг клиента.
> 4. Скажи юзеру перезапустить клиент и проверь, что инструменты появились.
>
> ⚠️ **Ключи API вводит юзер.** Не придумывай их и не подставляй примеры из документации.
> ⚠️ **Claude Code перезаписывает свой конфиг при работающем GUI.** Перед правкой `~/.claude.json` убедись, что приложение полностью закрыто, иначе правка потеряется.

**Что на выходе:** Claude умеет рисовать картинки и выкладывать их на CDN, возвращая готовую ссылку.
**Время:** 10 минут.

Слой необязательный. Нужен, если делаешь контентные сайты или пишешь статьи.

---

## Что это за серверы

**openrouter-image-mcp** — генерация и редактирование картинок через OpenRouter. Шесть моделей под короткими алиасами, один инструмент.

Почему через OpenRouter: готовые MCP для картинок обычно требуют прямого биллинга у Google — Google Cloud, Vertex AI, настройка платёжного аккаунта. За пределами США это отдельный квест. OpenRouter принимает карты, PayPal и крипту, кредиты не сгорают, API один на все модели.

**cloudinary-publish-mcp** — загрузка картинки на CDN и готовый набор ссылок под разные места: обложка, широкий баннер, мобильная версия, квадратная превьюшка, карточка для соцсетей, аватарка. Все с автоформатом и автокачеством: браузер получит WebP или AVIF, старый — JPEG.

Почему свой, а не официальный: у Cloudinary есть отличный MCP на два десятка инструментов для всего управления ассетами. Но для сценария «загрузи и дай ссылку» нужен один вызов, а в официальном инструменте загрузки был баг с путями на Windows.

## §1. Что потребуется

### Для генерации

- Аккаунт на **openrouter.ai** с пополнением от $5
- API-ключ оттуда (начинается с `sk-or-v1-`)

### Для публикации

- Бесплатный аккаунт **cloudinary.com** — 25 ГБ хранения и 25 ГБ трафика в месяц, карта не нужна
- Три значения из настроек: Cloud Name, API Key, API Secret

### Общее

**uv** — менеджер пакетов Python:

```powershell
irm https://astral.sh/uv/install.ps1 | iex
```

---

## §2. Установка

```bash
uv tool install --from git+https://github.com/<owner>/openrouter-image-mcp openrouter-image-mcp
uv tool install --from git+https://github.com/<owner>/cloudinary-publish-mcp cloudinary-publish-mcp
```

`uv` создаст изолированное окружение и при необходимости подтянет Python 3.12.

---

## §3. Подключение к клиенту

Найди путь к Python внутри venv:

```bash
uv tool dir
```

По умолчанию:

- **Windows:** `%APPDATA%\uv\tools\<имя-сервера>\Scripts\python.exe`
- **macOS / Linux:** `~/.local/share/uv/tools/<имя-сервера>/bin/python`

> ⚠️ **На Windows не используй лаунчер `.exe` из `~/.local/bin`** — он ведёт себя непредсказуемо в зависимости от PATH. Указывай Python из venv напрямую с `-m`, как в примерах ниже.

### Claude Code

Полностью закрыть приложение. Затем в `~/.claude.json`, в объект `mcpServers` верхнего уровня:

```json
{
  "mcpServers": {
    "openrouter-image": {
      "command": "C:/Users/YOU/AppData/Roaming/uv/tools/openrouter-image-mcp/Scripts/python.exe",
      "args": ["-m", "openrouter_image_mcp"],
      "env": {
        "OPENROUTER_API_KEY": "sk-or-v1-...",
        "OUTPUT_DIR": "C:/Users/YOU/Pictures/generated"
      }
    },
    "cloudinary-publish": {
      "command": "C:/Users/YOU/AppData/Roaming/uv/tools/cloudinary-publish-mcp/Scripts/python.exe",
      "args": ["-m", "cloudinary_publish_mcp"],
      "env": {
        "CLOUDINARY_CLOUD_NAME": "your-cloud-name",
        "CLOUDINARY_API_KEY": "your-api-key",
        "CLOUDINARY_API_SECRET": "your-api-secret"
      }
    }
  }
}
```

### Claude Desktop

То же самое, но в `claude_desktop_config.json`:

- **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
- **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`

После правки — запустить клиент заново.

## §4. Выбор модели и бюджет

Реальные цены за картинку:

| Алиас | Цена | Когда брать |
|---|---|---|
| `nb2` | $0.07 | дефолт на каждый день, хорошо рендерит текст внутри картинки |
| `pro` | ~$0.14 за вызов | сложные композиции; обычно возвращает сразу два варианта |
| `flash` | $0.04 | черновики |
| `gpt-mini` | $0.04 | самый дешёвый у OpenAI |
| `gpt` | $0.18 | узнаваемая «чатгпт-эстетика» |
| `gpt-pro` | $0.22 | обложка, когда нужен максимум |

> Для **технических схем** генеративные модели не годятся — подписи выходят кривыми. Схемы делай векторными (SVG), как в [`../article/assets/`](../article/assets/). Генерация хороша для обложек и иллюстраций.

## §5. Проверка слоя

Перезапустить клиент и убедиться, что инструменты появились:

- `mcp__openrouter-image__generate_image`
- `mcp__cloudinary-publish__publish_image`

Если не появились — в девяти случаях из десяти дело в пути к Python в конфиге. Проверь, что файл по указанному пути действительно существует.

Боевая проверка: попроси сгенерировать картинку и сразу опубликовать её. Должна вернуться ссылка вида `https://res.cloudinary.com/...`, которая открывается в браузере.
