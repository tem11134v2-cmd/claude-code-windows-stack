# Слой 0 — Железо и сеть

> **Claude: это рецепт слоя 0. Юзер скинул тебе этот файл — значит начинает сборку сервера с нуля.**
>
> **Важно: бо́льшую часть этого слоя ты выполнить не можешь** — здесь покупка VPS, вход по RDP на ещё не существующую машину и настройка GUI-приложения галочками. Твоя роль: провести юзера по шагам, сверяться с ним после каждого, и в конце прогнать проверки (§6), которые уже можно сделать командами.
>
> Если юзер уже на сервере и спрашивает про Proxifier — начинай с §4.
>
> **Голос:** коротко, по-русски. Перед §4 отдельно предупреди про правило localhost (§4.2) — это самая дорогая ошибка слоя.

**Что на выходе:** сервер куплен и доступен, весь его трафик идёт одним путём, утечек нет.
**Время:** 1–2 часа.

## §1. Прокси

Берётся **до** сервера: учётные данные понадобятся уже на первом часу работы.

### Что именно нужно

**Статический резидентский прокси, один выделенный IP.** Не ротационный, не датацентровый, не VPN.

| Параметр | Значение | Почему |
|---|---|---|
| Тип | Static Residential | Ротационный меняет IP каждые минуты — ломает залогиненные сессии |
| Exclusivity | Dedicated | IP только твой, не шарится |
| Replacements | без автоматических обновлений | IP не должен меняться сам |
| Bandwidth | Unlimited (fair use) | у разработки трафик небольшой, но считать его утомительно |
| Protocol | **HTTPS** | не SOCKS |
| Auth | Username / Password | |
| High IP reputation | взять, если есть за ~$1/мес | IP не в чёрных списках — меньше капч |

Не нужны: high concurrency, priority network, дополнительные IP.

**Цена ориентировочно $5–7/мес.**

### Что получишь

После оплаты в панели провайдера — четыре значения: `IP`, `порт`, `логин`, `пароль`. Они пойдут в Proxifier на каждой машине.

> ⚠️ **Эти четыре значения — секрет.** Не класть в репозиторий, не пересылать в открытых чатах, не вставлять в документы, которыми делишься по ссылке.

### Оговорка

Правила сервисов, которыми пользуешься, — на твоей ответственности. У многих в условиях есть пункты о том, откуда и как можно подключаться. Этот рецепт описывает сетевую часть; проверить ToS своих сервисов — твоя работа.

## §2. VPS

### Проверенное

| Провайдер | Локации | Конфигурация | Цена |
|---|---|---|---|
| **PQ.Hosting** | Германия, Нидерланды | KVM-3: 4 vCPU, 8 ГБ, NVMe | ~1 800 ₽/мес |
| **Timeweb Cloud** | Frankfurt, Москва, СПб | DE-80: 4 vCPU, 8 ГБ, 80 ГБ NVMe | ~8 690 ₽/мес (Frankfurt) |

Оба ставят Windows Server 2022 из шаблона при заказе и принимают карты, СБП и крипту.

### Во что упираются остальные

| Провайдер | Проблема |
|---|---|
| Hetzner | Верификация документом, российские паспорта часто отклоняет |
| IONOS DE | Минимальный контракт 24 месяца |
| Contabo Cloud VPS | Германию отдельно не выбрать, только «EU» |
| netcup | Windows не из шаблона, нужна своя ISO и лицензия |
| AEZA Германия | Часто нет в наличии |

### Конфигурация под задачу

| Что делает машина | Минимум | Комфорт |
|---|---|---|
| Один человек, только браузер | 2 vCPU, 4 ГБ | 4 vCPU, 8 ГБ |
| Один человек + Claude Code | 4 vCPU, 8 ГБ | 4 vCPU, 8 ГБ |
| Два человека, две RDP-сессии | 4 vCPU, 8 ГБ | 8 vCPU, 12+ ГБ |

Диск: 80 ГБ NVMe хватает с запасом.

### Локация

Физическое расположение на исходящий трафик не влияет — наружу виден IP прокси. Выбор по другим критериям:

- **Россия** — бюджет ограничен (дешевле в 2–5 раз), ты работаешь за экраном и заметишь сбой сразу.
- **Европа** — Claude Code работает в фоне без надзора, нужен предсказуемый сетевой стек, не хочется, чтобы между сервером и прокси оказалась чья-то блокировка.

### При заказе

1. Раздел **Cloud Servers**, не shared-хостинг.
2. ОС: **Windows Server 2022**.
3. Публичный IP: **включён** (без него не зайти по RDP).
4. Ничего из managed-услуг и дополнительных IP.
5. Срок: месяц, на пробу.

Через 5–10 минут в панели появятся IPv4, логин `Administrator` и одноразовый пароль.

## §3. Первый заход на сервер

Зайти по RDP под `Administrator`. Сразу:

1. **Сменить пароль** — `Ctrl+Alt+End` → Change password. Длинный.
2. **Скачать Chrome** через Edge.
3. **Скачать Proxifier** с официального сайта — Standard Edition, триал 31 день, лицензия $39.95 разово на машину.

Пока Proxifier не настроен, не стоит логиниться на сервере в рабочие аккаунты сервисов — IP машины попадёт к ним в логи как твой обычный адрес входа, и потом каждая смена IP будет вызывать подтверждения.

## §4. Proxifier

Установка обычная: Next → Install. Дальше пять шагов, порядок важен.

### §4.1. Добавить прокси

`Profile → Proxy Servers → Add`

| Поле | Значение |
|---|---|
| Address | IP из §1 |
| Port | порт из §1 |
| Protocol | **HTTPS** (не SOCKS) |
| Use authentication | ✓, логин и пароль из §1 |

Нажать **Check** и дождаться `Test passed`.

Не пропускай Check: он ловит опечатку в пароле **до** того, как ты заворотишь в этот прокси весь трафик машины.

### §4.2. Правило для всего трафика

`Profile → Proxification Rules → Default rule → Edit → Action: Proxy HTTPS [твой прокси]`

> ⚠️ **Правило для localhost, которое стоит выше дефолтного, не трогать.**
>
> Оно единственное, что держит RDP-соединение. Завернёшь его в прокси — потеряешь доступ к серверу и будешь восстанавливать через консоль в панели провайдера. Самая дорогая ошибка этого слоя.

### §4.3. Защита от утечек

`Profile → Advanced`

| Настройка | Значение |
|---|---|
| **DNS and IP Leak Prevention Mode** | ✓ включить |
| Bypass UDP Traffic | переключить на **Block Traffic to All UDP Ports if Matched the Rule** |
| Block Non A/AAAA Queries if DNS through Proxy | ✓ |
| Handle Direct Connections | ✓ (обычно уже стоит) |
| Infinite Connection / Name Resolution Loop Detection | ✓ |

Первая строка — это kill switch: всё, что пытается пойти мимо прокси, блокируется на уровне сетевого стека. Если прокси ляжет, трафик остановится, а не пойдёт напрямую.

Блокировка UDP закрывает утечки через WebRTC и QUIC.

### §4.4. DNS через прокси

`Profile → Name Resolution → ✓ Resolve hostnames through proxy`

Без этого IP у тебя будет чужой, а DNS-запросы — свои. Это видно в тесте из §6.

### §4.5. Автозапуск

`Settings`

- ✓ **Start with Windows**
- ✓ **Hide on close**

Второе важнее, чем кажется: без него Proxifier однажды закроется крестиком, и машина останется без защиты ровно до того момента, когда ты это заметишь. С галкой крестик сворачивает в трей.

## §5. Настройки Windows

### Часовой пояс

`Settings → Time & Language → Date & Time`

Выставить ту зону, в которой реально работаешь. Set time automatically: On.

Это не косметика: таймзона сервера попадает в логи, в даты коммитов и в расписания задач. Когда через месяц разбираешь, почему ночная задача отработала «не тогда», неверная таймзона стоит час жизни.

### Язык системы

Английский. Не из эстетики — текст ошибки на английском гуглится, на русском нет. Русский можно оставить вторым в Preferred languages для печати.

### Электропитание — не давать серверу засыпать

`Control Panel → Power Options → High performance → Change advanced power settings`

| Параметр | Значение |
|---|---|
| Hard disk → Turn off after | Never |
| Sleep | Never |
| Display | Never |

**Критично для фоновой работы.** Иначе ночью сервер заснёт вместе с твоей задачей.

### Не вырубать RDP-сессию по таймауту

`Win+R → gpedit.msc → Computer Configuration → Administrative Templates → Windows Components → Remote Desktop Services → Remote Desktop Session Host → Session Time Limits`

Все три — в **Disabled**:

- Set time limit for active but idle Remote Desktop Services sessions
- Set time limit for active Remote Desktop Services sessions
- Set time limit for disconnected sessions

Последний особенно: он отвечает за то, чтобы отключённая сессия (и запущенный в ней Proxifier с твоими задачами) продолжала жить.

### Две одновременные RDP-сессии

Нужно, только если пойдёшь в слой 2. Там же, `gpedit.msc → ... → Connections`:

- Restrict Remote Desktop Services users to a single session → **Disabled**
- Limit number of connections → **Enabled** → 2 или 3

### Отложить обновления

`Settings → Windows Update → Advanced options → Pause updates` на максимум.

Чтобы автообновление не перезагрузило сервер посреди работы.

### Телеметрия

`Settings → Privacy & Security → Diagnostics & feedback` → Diagnostic data: Required only, остальное Off.

## §6. Проверка слоя

**Перезагрузить сервер.** Дождаться полной загрузки. Убедиться, что иконка Proxifier в трее активна.

### Тесты в браузере

| Тест | Что должно быть |
|---|---|
| `whoer.net` | IP, страна и провайдер — те, что у прокси |
| `browserleaks.com/webrtc` | WebRTC Leak Test: **No Leak**; Local IP и Public IP пустые |
| `dnsleaktest.com` → Standard test | DNS-серверы в той же стране, что прокси; посторонних нет |
| `ifconfig.me` или `ipinfo.io` | тот же IP прокси |

Последний — самый «голый» сервис: показывает ровно тот IP, с которого пришёл запрос. Именно так тебя видит любой сайт.

### Командой

```powershell
(Invoke-RestMethod https://api.ipify.org?format=json).ip
```

Должен вывести IP прокси, а не IP сервера из панели провайдера.

---

> ⚠️ **Если хоть один тест показывает не тот IP или утечку — слой не пройден.**
>
